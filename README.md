A make.fun entry for the **Worst Monday One-Liners** bounty: a small
stdlib-only Python program that writes exactly one funny line — at most
140 characters, a joke about an AI agent's worst Monday — to `entry.txt`.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -S main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
